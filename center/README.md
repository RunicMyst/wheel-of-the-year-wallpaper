# Centre Art

The centre circle shows the Vegvísir (Norse compass) with its ring of Elder Futhark runes by
default. To use something else, drop one picture into this folder — it is cropped to the
circle (a square picture works best). Delete it to get the Vegvísir back.

If there are several pictures here, they take turns, a different one each day.

Only use pictures you have the right to use. Pictures in this folder stay on your computer
and are not included when this project is shared (see `.gitignore`).
