# Wedge art

The 12 large wedges between the centre circle and the purple zodiac ring can each show a
picture. Each wedge sits under a month on the outer rings, so the folders are named by month.

- Drop a picture into a month's folder and it fills that wedge, cropped to the wedge's shape.
- Several pictures in one folder take turns, a different one each day.
- Empty folder: the wedge stays plain dark, as designed.
- The current month's wedge is shown at full brightness; the others are gently dimmed.
- .jpg, .jpeg, .png or .webp. Pictures with the interesting part in the middle crop best.

Only use pictures you have the right to use.
