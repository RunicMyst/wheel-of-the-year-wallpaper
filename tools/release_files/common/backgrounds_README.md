# Background photos

The picture behind the wheel comes from these folders — one folder per Sabbat.

- While a Sabbat is current (from its date until the next Sabbat), the wallpaper uses the
  photos in that Sabbat's folder.
- Put in as many photos as you like, or none. Every photo is used: a different one each
  day, taking turns. Folders don't need the same number of photos.
- Empty folder: the background is plain black.
- Any shape or size: landscape or portrait, .jpg, .jpeg, .png or .webp. Bigger is better —
  ideally at least as wide as your screen.
- The wheel goes on whichever side of the photo is darker or emptier. To choose yourself,
  end the file name with _wheel-left or _wheel-right, e.g.  altar_wheel-right.jpg
- Anything else in here (sub-folders, text files) is ignored, so you can keep a
  "maybe" folder inside.

Only use photos you have the right to use — your own, or ones licensed for your use.
