# Sabbat-ring symbols

The Sabbat ring has four slots without a Sabbat name. A symbol can go in each — a rune,
pentacle, triple moon, or anything you like. Each folder is named after the two Sabbats
either side of its slot:

  Samhain-Yule       (top of the wheel)
  Yule-Imbolc
  Ostara-Beltane
  Litha-Lughnasadh

- Drop a picture into a folder and it is fitted inside that slot, turned to follow the ring.
- Pictures with a transparent background (.png) look best - the ring shows through.
- Several pictures in one folder take turns, a different one each day.
- Empty folder: the slot stays plain, as designed.
- These slots aren't Sabbats, so they're never highlighted; they're dimmed with the rest of
  the ring.

Only use pictures you have the right to use.
