# Backgrounds

The wallpaper's background photo comes from these folders. Add or delete photos
freely — nothing else needs to change.

- **One folder per Sabbat.** While a Sabbat is active (from its date until the next
  Sabbat), the wallpaper uses photos from that Sabbat's folder.
- **Any number of photos.** Every photo in the folder is used — a different one each
  day, cycling through them all. One photo is fine; so is none.
- **Empty folder?** The background is plain black.
- **Any shape or size.** Landscape or portrait, `.jpg`, `.jpeg`, `.png` or `.webp`.
  Larger is better (ideally at least as wide as your screen).
- **Wheel placement.** The wheel sits on whichever side of the photo is darker/emptier.
  To choose yourself, end the file name with `_wheel-left` or `_wheel-right`
  (e.g. `altar_wheel-right.jpg`).
- **`Sorting file/`** is an inbox for photos that haven't been sorted yet. It is never
  used for the wallpaper; move a photo into a Sabbat folder to use it.

Only use photos you have the right to use. Photos in these folders are for your own
desktop and are not included when this project is shared (see `.gitignore`).
