# Wedge Art

The 12 large wedges between the centre circle and the purple zodiac ring can each show a
picture. Each wedge sits under a month on the outer rings, so the folders are named by month.

- Drop a picture into a month's folder and it fills that wedge, cropped to the wedge's shape.
- Several pictures in one folder? They take turns — a different one each day.
- Empty folder: the wedge stays plain dark, as in the original design.
- The current month's wedge is shown at full brightness; the others are gently dimmed.
- `.jpg`, `.jpeg`, `.png` or `.webp`. Anything with the interest near the middle crops best.

Only use pictures you have the right to use. Pictures in these folders stay on your computer
and are not included when this project is shared (see `.gitignore`).
